# Skill Catalogue

## Work planning

### ado-workplan

ADO-only scheduler for active sprint work. It reconciles prior-day note completion with live work-item state, renders remaining IST work blocks, and updates the Zettelkasten daily checklist.

### dayplan

Combined scheduler that merges ADO and DRI inputs under an incident-first priority model and adjusts capacity when DRI duty is active.

## Persistent knowledge and continuity

### context-offload

Defines the per-base `.agent-context` four-file store, persona registry, hydration rules, continuous offload behavior, freshness threshold, and honesty invariants.

### context-mesh

Indexes context stores and zmem into a read-mostly portfolio graph with a startup digest, structured index, dashboard, freshness status, and evidence-ranked artifact provenance.

### career-forensics

An evidence-first Engineering Career Operating System that maintains an append-only knowledge base, reconstructs technical history, tracks confidence and growth, and actively runs memory-recovery sessions.

## Content and documentation systems

### clipfarm-leetcode

The operational contract for ClipFarm coding/system-design editing: source preparation, complete transcript review, vertical/system-design/horizontal routing, editorial plans, immutable drafts, output ASR, visual review, publishing, galleries, thumbnails, captions, and rights/provenance.

### documentation-mesh

The Agency-facing skill for a local documentation-analysis runtime that discovers Markdown, builds evidence-backed relationships, evaluates health, records Git provenance, validates a deterministic JSON index, and publishes an offline dashboard.

### speak

The Copilot Speak plugin skill that routes requests for spoken output to a local MCP server backed by Windows text-to-speech.

## Research

### nse-advisor

An NSE-only paper-trading research workflow that combines sector analysis, fundamental and technical screening, risk-bounded allocation math, entry/exit planning, and a fixed recommendation format.

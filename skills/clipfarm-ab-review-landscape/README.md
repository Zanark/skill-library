# Matched landscape A/B review

Compare complete original and graded pictures at matching source times.

- **Inputs:** one real grading candidate, its actual source and selected preview ranges.
- **Mechanism:** the shared grading comparison path, not a CSS filter simulation.
- **Result:** a side-by-side review MP4, not a second approved final.
- **Review:** matched timing, complete pictures, scopes and actual transitions.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). A current grading-capable
ClipFarm checkout is required. Generating review evidence does not require or
fabricate final-look approval; do not add a new soundtrack.

# Full-room portrait podcast teaching

Place a complete padded two-host room strip beneath teaching and captions.

- **Inputs:** permitted room artwork, narration, source timing and newly
  reviewed image-specific speaker contours.
- **Mechanism:** a fresh request-local producer; speaker estimation is not
  verified human identity or a shared animation engine.
- **Result:** a portrait explanation with the full-room composition.
- **Review:** encoded teaching, art bounds, speaker transitions, captions and cover.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use a current ClipFarm
checkout; masks from a different artwork hash cannot be reused blindly.

# Camera-free portrait coding

Use the larger code pane when the recording genuinely has no camera/avatar.

- **Inputs:** reviewed coding footage, explicit camera absence and relevant
  code/result regions.
- **Mechanism:** the shared workflow with camera_mode absent; detection failure
  alone is not evidence that the source has no camera.
- **Result:** a 9:16 coding clip with lower captions and no invented face crop.
- **Review:** actual title/code/captions, meaningful cuts and result animation.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use a current ClipFarm
checkout; a code screenshot is not a substitute for an absent face.

# SDR color grading

Editable looks through the real local grading engine, with moving A/B evidence
and immutable feedback revisions.

- **Inputs:** supported SDR media or an exact existing session and an authored brief.
- **Mechanism:** the shared grading CLI or supplied Studio origin, never a parallel
  filter implementation or competing worker.
- **Result:** a resumable session and, after explicit exact-candidate approval,
  an engine-exported edition preserving the supported source contract.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Requires a current
ClipFarm grading-capable checkout. Inspect actual previews/scopes; silence,
encoding success and an agent's preference are not user approval.

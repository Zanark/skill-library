# Early cinematic music draft

Show an original full-song story/look as a clearly labelled concept or animatic.

- **Inputs:** a permitted song/lyrics, original request time and an explicit
  early-draft brief.
- **Mechanism:** lightweight new local production with declared proxy settings;
  never a silent quality reduction of a requested final.
- **Result:** a visibly marked full-song draft, storyboard and sampled evidence.
- **Review:** a few actual story states, full-audio integrity and cover.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Requires a current
ClipFarm checkout. Lyrics are estimated or absent; full approval/upload-ready
remain false. Later full production is a new immutable edition, not a rename.

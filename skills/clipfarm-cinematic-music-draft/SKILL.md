Use this route for an explicit early draft/concept/animatic request. It is not
permission to relabel an unrelated fast production or lower a requested final.
Create a new story and request-local producer; do not replay a sealed old film.

Keep the ENTIRE original song unless an excerpt is explicitly requested.
Show a beginning, development and payoff across it. Save time with blocked
staging, simpler geometry/materials and a clearly declared proxy, not missing
sections. The proposed default proxy is 720x1280/24fps; retain a real 1080x1920
center-3:4-safe cover. These are draft choices, not shared renderer settings.

Do not run singing ASR or exhaustive lyric/shot/join review by default.
If supplied lyrics are displayed, preserve the wording and label their timing
estimated; omit unsupported word highlighting/karaoke. A draft can omit a
lyric window rather than imply synchronization it does not have.

Check source preservation, full audio/duration, basic decoding and a small set
of actual native/encoded story states. Fix encountered defects. Generate the
one session index directly with known copy/folder/CSP helpers; no gallery
desktop/phone/browser QA unless asked.

Make DRAFT visible in the movie and gallery; keep full-review/user-approval/
upload-ready flags false. Deliver the storyboard, concept MP4, cover and exact
remaining checks. A later full request uses a NEW immutable full-quality
edition and the full-review skill, never a rename or approval toggle.

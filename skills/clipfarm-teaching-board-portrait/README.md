# Causal portrait teaching board

Animate narrated operations without a camera or host panel.

- **Inputs:** reviewed speech/narration, a source-time map and an explicit
  action ledger with stable object identities.
- **Mechanism:** a newly authored request-local compositor using local tools,
  not an automatic scene-generation CLI.
- **Result:** an open 9:16 teaching board with causal intermediate states
  and lower captions.
- **Review:** actual construction, comparison, updates, outcomes and joins.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use the current ClipFarm
environment. Changing captions over a finished diagram is not causal animation.

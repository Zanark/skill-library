# Side-by-side podcast close-ups

Use two enlarged bottom host cards beneath an open teaching area.

- **Inputs:** permitted matching artwork, narration and inspected mouth/contour
  assets tied to the source/speaker clock.
- **Mechanism:** a new local compositor using the selected close-up layout,
  not the stacked eye-study composition.
- **Result:** portrait teaching with side-by-side hosts and rounded captions.
- **Review:** real mouth/teaching transitions, card bounds and full/center-safe cover.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). A current ClipFarm
checkout is required. A layout reference does not approve each new film.

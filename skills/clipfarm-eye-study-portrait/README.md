# Stacked-host eye and arm study

Study blink/gaze movement and a protected near arm in vertically stacked host cards.

- **Inputs:** permitted art/speech, perspective-fitted eyes and protected face/prop masks.
- **Mechanism:** a new isolated local study with explicit eye direction, mouth/speech
  clock and arm constraints.
- **Result:** a scoped portrait study, not the side-by-side production layout.
- **Review:** both eyes, transitions, source timing and stationary protected content.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Requires a current
ClipFarm checkout; do not claim a general eye-tracking rig or automatic approval.

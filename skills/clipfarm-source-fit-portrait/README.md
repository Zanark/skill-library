# Full-source portrait Fit

Contain the complete sharp source picture over its blurred duplicate.

- **Inputs:** a permitted recording, faithful source-bound captions and one owned
  Studio project/cut.
- **Mechanism:** the existing Studio Fit renderer and optimistic project/job flow.
- **Result:** a full-frame portrait composition; the historical low-resolution
  demonstration is not a final-quality guarantee.
- **Review:** source bounds, captions, exported geometry and preview/final role.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use a current ClipFarm
checkout. This is not face tracking, selective code cropping or an automatic complete solve.

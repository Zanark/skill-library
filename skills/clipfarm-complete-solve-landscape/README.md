# Complete native-layout solves

Preserve one chronological complete solve in the original landscape arrangement.

- **Inputs:** a completed LeetCode source solve, verified quiet caption regions
  and permitted cover artwork.
- **Mechanism:** explicit horizontal workflow mode, preserving meaningful
  silent work without the vertical short-clip cap.
- **Result:** one full solve per completed problem and a matching cover/intro.
- **Review:** every join, genuine completion, source framing, caption space
  and truthful complexity/cover basis.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use a current ClipFarm
checkout. A scoped excerpt or incomplete attempt is not a complete solve.

# Native portrait SDR finish

Change a supported SDR look while retaining native portrait geometry and timing.

- **Inputs:** supported portrait media, a genuine input interpretation and a saved
  look brief/recipe.
- **Mechanism:** the shared grading engine and its existing session/version/job flow.
- **Result:** a source-preserving portrait grade, not forced 9:16 reframing.
- **Review:** actual moving A/B evidence, encoded source contract and explicit
  exact-candidate approval before final export.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Requires a current
grading-capable ClipFarm checkout; do not substitute a parallel filter pipeline.

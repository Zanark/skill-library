# Portrait system-design clips

Select meaningful explanations or genuine humor from diagrams, slides and code.

- **Inputs:** a design recording, complete topic understanding and verified
  content regions.
- **Mechanism:** explicit system-design routing in the shared editorial CLI.
- **Result:** vertical design clips with question-only heading and faithful
  lower captions.
- **Review:** actual diagrams, joins, captions, coverage and any corrections.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Requires a current
ClipFarm checkout. Do not invent LeetCode submissions/runtimes or a horizontal
complete-design-solve route.

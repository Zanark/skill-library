# Portrait coding with camera

Keep the actual source camera/avatar above relevant code, with lower captions.

- **Inputs:** a reviewed camera-present coding recording and verified camera,
  code and any result-panel regions.
- **Mechanism:** the existing source-video workflow and unapproved profile/cut
  examples, populated from the new recording.
- **Result:** a 9:16 explanation, debug, submission or genuine-humor clip.
- **Review:** real runtime evidence where used, animated result zoom, persistent
  question title, source-camera sync and actual encoded joins.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md) in a current ClipFarm
checkout. Do not invent a camera, performance result, approval or upload.

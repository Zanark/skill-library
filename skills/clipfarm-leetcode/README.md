# Coding and system-design editorial workflow

The main source-video workflow: local transcripts, complete source understanding,
explicit edits, immutable drafts and reviewed local delivery.

- **Inputs:** a permitted recording, optional transcript and original request time.
- **Routes:** vertical LeetCode, explicit vertical System Design, or explicitly
  requested complete native-layout landscape solves.
- **Mechanism:** existing prepare/inspect/validate/draft/review-transcribe/publish
  CLI stages; semantic selection remains the editor's responsibility.
- **Result:** source-grounded clips in one timestamped session gallery.

Read [SKILL.md](SKILL.md) and [RUNBOOK.md](RUNBOOK.md). Use a current ClipFarm
checkout. Recognition is fallible; successful rendering is not editorial/user
approval or platform posting. Preserve sources and exact output evidence.

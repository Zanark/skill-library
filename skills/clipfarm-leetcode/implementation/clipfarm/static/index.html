    02 / FIND THE WORDS

    The story, with timestamps.

    Import timed captions to unlock suggested cuts. Imported captions replace the current transcript; you can edit every line afterward.

    TXT accepts "00:00:17.199 Spoken words" or a timestamp above a paragraph. Start-only exports need inferred end times; granular lines work better than long blocks.

    Plain, untimestamped text cannot be aligned by itself. Use on-device transcription below to generate timings from the original audio.

    No transcript? Keep it local.

    First use downloads the chosen speech model and needs internet access. Audio processing then runs locally—your recording is not sent to an external AI service. Long recordings can take significant time. Existing captions will be replaced.
    03 / FIND THE GOOD PART

    A starting point, not a verdict.

    Find promising excerpts using transcript structure, phrasing, and your keywords. These are editorial heuristics—not predictions of reach or virality.

    Suggestions are added to your existing cuts. Review context, correct transcription errors, and adjust each cut before exporting. Unsaved edits are saved first.

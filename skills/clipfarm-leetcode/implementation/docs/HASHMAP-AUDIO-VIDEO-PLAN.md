# Audio-led animation: preservation boundary

The original request-specific production plan is retained only in the private
migration archive's `clipfarm\docs` collection. It includes local sources,
review evidence, immutable deliveries and temporary producers; none is silently
discarded or presented as a general shared-engine feature.

Reusable requirements: preserve full source audio when requested, drive topic
headings and chapter timestamps from one timeline, perform narrated operations
causally, reserve caption/teaching clearance, and inspect actual encoded output.
Source generation or successful encoding is not editorial or user approval.

placeholders, use local style and retain applicable repository contracts.

For a new project, copy index/workstream/ledger to its authorized `TODO` folder
using suitable stable numbers/names. Do not copy this README or Markdown forms
into a TODO folder whose local rule permits only `.todo` files.
Do not automatically create all templates: select the smallest useful set.
